# 7-day Instagram / TikTok plan: "I built a paper-trading robot and show every loss"

**Every post must carry this line on screen and in the caption: "Paper trading project. Educational only. Not financial advice. No real money. Results can be bad."**
Rules for every item: never promise or imply profit; never show a "win" without showing the losses beside it (the real numbers so far are poor: PF 0.75, -87.96 on $100 paper money); never tell viewers to copy signals; never ask for money; no referral links to exchanges. **Check Pakistan's rules on financial content/advertising (SECP / PTA guidance on investment advice) and each platform's financial-content policy before posting - NOT VERIFIED here.** Use AI voice/video tools only with the platform's "AI-generated" label if it asks for one. Do not show tokens, chat ids, channel links or dashboards with secrets.
